Bugs Identified and Fixed in Starter Code
=========================================

1. testbed_description/CMakeLists.txt
   - Bug: `ament_package` was missing parentheses `()`, causing a CMake configure error. Also `config` directory was not installed.
   - Fix: Corrected to `ament_package()` and included `config` in `install(DIRECTORY meshes urdf launch rviz config DESTINATION share/${PROJECT_NAME})`.

2. testbed_bringup/CMakeLists.txt
   - Bug: `maps` directory was missing from `install(DIRECTORY ...)`, so `testbed_world.yaml` and `testbed_world.pgm` were not copied to the install share directory.
   - Fix: Added `maps` to `install(DIRECTORY launch maps DESTINATION share/${PROJECT_NAME}/)`.

3. testbed_gazebo/CMakeLists.txt
   - Bug: `models` directory was missing from `install(DIRECTORY ...)`, preventing Gazebo from finding custom world models.
   - Fix: Added `models` to `install(DIRECTORY launch worlds models DESTINATION share/${PROJECT_NAME}/)`.

4. testbed_bringup/maps/testbed_world.yaml
   - Bug: `image: wrong_path_testbed_world.pgm` pointed to a non-existent PGM file.
   - Fix: Updated to `image: testbed_world.pgm`.

5. testbed_description/urdf/testbed.xacro, testbed.gazebo & testbed_gazebo (ROS 2 Jazzy / Gazebo Sim Compatibility)
   - Bug: Starter code targeted Gazebo Classic (`gazebo_ros` / `libgazebo_ros_diff_drive.so` / `libgazebo_ros_ray_sensor.so`), which is not available on ROS 2 Jazzy (`gz sim`). Additionally, `testbed.ros2_control.xacro` was not included in `testbed.xacro`, `robot_state_publisher` lacked `use_sim_time: True`, and the lidar max range (1.5 m) was too short for the ~20 m playground room.
   - Fix:
     * Included `testbed.ros2_control.xacro` in `testbed.xacro` and set `use_sim_time: True` in `robot_description.launch.py`.
     * Configured `testbed.gazebo` with `gz_ros2_control::GazeboSimROS2ControlPlugin` (remapping `/diff_drive_base_controller/cmd_vel` -> `/cmd_vel` and `/diff_drive_base_controller/odom` -> `/odom`), `gpu_lidar` (`/scan`, max range 12.0 m), `imu` (`/imu`), and caster/wheel friction coefficients.
     * Updated `spawn_playground.launch.py` and `spawn_testbed.launch.py` to use `ros_gz_sim`, `ros_gz_bridge` (`/clock`, `/scan`, `/imu`), and `controller_manager` spawners (`joint_state_broadcaster`, `diff_drive_base_controller`).
     * Added Gazebo Sim system plugins (`Physics`, `UserCommands`, `SceneBroadcaster`, `Sensors`, `Imu`) to `testbed_playground.world`.
