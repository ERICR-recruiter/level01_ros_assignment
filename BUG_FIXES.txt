BUG FIXES AND IMPLEMENTATION IMPROVEMENTS
========================================

Project: Level 1 – ROS 2 Navigation Assignment

--------------------------------------------------
1. MISSING MAP DIRECTORY IN PACKAGE INSTALLATION
-------------------------------------------------

File:
testbed_bringup/CMakeLists.txt

Issue:
The original installation rule included only the launch directory.
The maps directory containing testbed_world.yaml and testbed_world.pgm was not included in the package installation.

Correction:
Added the maps directory to the existing CMake install rule.

Updated installation rule:

install(
  DIRECTORY
    launch
    maps
  DESTINATION
    share/${PROJECT_NAME}/
)

Verification:
- Rebuilt testbed_bringup successfully.
- Verified that testbed_world.yaml and testbed_world.pgm were installed under:

  install/testbed_bringup/share/testbed_bringup/maps/

- Successfully launched the Map Server using the installed
  map resources.
